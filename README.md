# Italy Weather Trip Dashboard

Weather-driven Italy travel planner.

## Current features
- 3 / 7 / 10 / 14 day weather dashboard
- Open-Meteo by default
- Optional Google Weather + Open-Meteo multi-source mode
- Forecast confidence labels
- Editable destinations and stay duration
- Automatic or manual current location
- Next-destination recommendation using weather, stay duration, and distance
- Editable modules and city grouping
- Favorites, search, sorting
